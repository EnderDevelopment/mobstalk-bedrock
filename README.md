# MobsTalk: Minecraft Bedrock Plugin

MobsTalk is a Minecraft Bedrock plugin that brings life to mobs by enabling them to speak in complete sentences, displayed in speech bubbles above their heads, similar to comic book dialogues. Each mob has over 12,000 unique phrases in Portuguese, and villagers have different dialogues based on their professions and ages. The plugin includes a custom menu for interacting with mobs, quests, RPG items, and animations. It uses vanilla sounds and features offline interactions between mobs, such as villagers calling for help through speech bubbles. The plugin is designed to be immersive and engaging, with a significant file size exceeding 10 MB to accommodate the extensive dialogue and additional features.

## Install

1. Download the MobsTalk plugin from the [GitHub releases page](https://github.com/EnderDevelopment/MobsTalk/releases).
2. Place the downloaded `.jar` file into the `plugins` folder of your Minecraft Bedrock server.
3. Start or restart your Minecraft Bedrock server to load the plugin.

## Use

1. Launch your Minecraft Bedrock world.
2. Interact with mobs to see them speak in speech bubbles.
3. Use the custom menu to converse with mobs, complete quests, and engage in RPG activities.
4. Enjoy the extensive dialogue, animations, and offline interactions between mobs.
